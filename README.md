# 공항 주차장 실시간 현황

김포·김해·제주공항에 갈 때 **어느 주차장에 댈지** 출발 직전에 판단하기 위한 휴대폰용 웹앱.

같은 공항이라도 주차장별 상황이 크게 다르다. 2026-09-15 10:13 실측에서 김포 국내선 제1주차장은 잔여 0면이었지만 국제선 주차빌딩은 161면이 비어 있었다.

## 구조

요청이 올 때만 도는 프록시 하나가 전부다. 저장소도, 스케줄러도 없다.

```
휴대폰 ──▶ Vercel (서울 icn1)
             ├─ public/        정적 파일
             ├─ api/login.py   암호 확인 → 세션 쿠키
             └─ api/parking.py 원천 호출 → 등급·접근성 결합 → JSON
                      │
                      ▼
             apis.data.go.kr
```

```
api/               Vercel 서버리스 함수 (진입점)
collector/         공유 로직 — api(호출·파싱) auth(인증) grading(등급) live(응답 조립)
data/              주차장별 도보·셔틀 접근성 (API로 오지 않는 정적 정보)
public/            웹앱. 빌드 도구 없음
probe/             갱신주기·변화량 실측 도구. 앱 코드가 아니다
tools/             암호 해시 생성기 (로컬 전용)
```

## 왜 서울 리전인가

**공공데이터포털이 해외 IP를 차단한다.** GitHub Actions 러너(미국 애리조나)에서 `apis.data.go.kr`로의 TCP 443이 거부가 아니라 **드롭**된다 — `connect=0.000000s` 후 타임아웃. 같은 러너에서 `api.github.com`은 0.16초에 응답했으므로 러너 네트워크 문제가 아니다.

서울(icn1)에서는 141ms에 응답한다. **`vercel.json`의 `regions`를 바꾸면 앱 전체가 죽는다.**

## 왜 추세가 없는가

"오늘 곡선"을 그리려면 24시간 도는 수집기가 필요하고, 그건 상시 켜진 기기나 유료 인프라를 뜻한다. 둘 다 두지 않기로 했다.

대신 **신선도가 좋아졌다.** 원천이 60초마다 갱신되는데 요청할 때마다 직접 부르므로 화면은 최대 75초 이내의 값을 보여준다. 수집기를 두던 시절에는 최대 35분이었다.

"지금 차오르는 중"은 앱이 열려 있는 동안 브라우저가 직전 값과 비교해 만든다 (`public/app.js`의 `computeTrend`). 서버는 이력을 갖지 않는다.

## 데이터 출처

한국공항공사 **전국공항 실시간 주차정보** (공공데이터포털, 데이터셋 15056803)

```
GET https://apis.data.go.kr/B551178/parking-realtime-status/info
```

실측으로 확인한 특성:

- 원천은 **정확히 60초마다** 갱신된다 (41분간 40회 연속, 편차 0)
- `schAirportCode`를 생략하면 **1회 호출로 전국 25개 주차장**이 모두 온다
- **점유율이 100%에 닿으면 카운터가 고정된다.** 만차 주차장의 입출차 정보는 신뢰할 수 없어 추세를 표시하지 않는다

## 배포 설정

Vercel 프로젝트에 환경변수 3개가 있어야 한다. 하나라도 없으면 해당 기능이 **거부로 끝난다** (통과가 아니다).

| 이름 | 내용 |
|---|---|
| `KAC_SERVICE_KEY` | 공공데이터포털 서비스키 |
| `APP_PASSWORD_HASH` | 접속 암호의 PBKDF2 해시 |
| `SESSION_SECRET` | 세션 쿠키 서명용 난수 |

뒤의 두 개는 이 명령으로 만든다. 암호를 인자로 받지 않으므로 셸 기록에 남지 않는다.

```
python tools/make_password_hash.py
```

## 로컬 개발

```
python -m pytest -q          # 63개
python probe/check_join.py   # 주차장명 조인이 깨지지 않았는지
```

`probe/`는 서비스키가 필요하다. `probe/.env.example`을 `probe/.env`로 복사해 채운다. `.env`는 `.gitignore`로 제외되며, **`.env.example`은 커밋되는 템플릿이므로 실제 키를 넣지 않는다.**

## 보안 결정 기록

**인증을 둔다.** 다루는 데이터 자체는 공공데이터라 기밀이 아니지만, 불특정 다수에게 서비스를 운영하는 상태를 만들지 않기 위해서다. 암호는 평문으로 저장하지 않고 PBKDF2-HMAC-SHA256 해시만 환경변수에 둔다. 세션은 서버가 서명한 HttpOnly 쿠키이며, 판단은 전부 서버에서 한다.

서버리스라 저장소 없이 시도 횟수를 셀 수 없다. **검증 1회에 드는 시간(반복 60만 회)이 무차별 대입에 대한 유일한 방어선**이다.

**서비스키는 함수의 환경변수에만 있다.** 휴대폰 브라우저가 `data.go.kr`을 직접 부르지 않으므로 키가 노출되지 않는다.

정적 파일(HTML·CSS·JS)은 인증 없이 받을 수 있다. 내용이 빈 껍데기이고 데이터 API가 막혀 있어 실질적으로 이용할 수 없다.
